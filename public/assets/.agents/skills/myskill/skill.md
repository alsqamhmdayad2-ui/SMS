# 🧠 Project Skills - School Management System

## 📌 Overview
This project is a simple School Management System.  
It helps manage students, teachers, parents, and admin tasks in an organized way.

---

## 💻 Technical Skills Used

### 1. Frontend
- HTML5 → for page structure
- CSS3 → for styling and layout
- Bootstrap 5 → for responsive design
- JavaScript → for dynamic behavior

### 2. Backend (if used)
- PHP → for server-side logic
- MySQL → for database management

### 3. Other Skills
- CRUD Operations (Create, Read, Update, Delete)
- Form handling and validation
- Working with tables and data display
- LocalStorage (in some parts)

---

## 🧩 Features of the System

### 👨‍💼 Admin Features
- Add / Edit / Delete users (students, teachers)
- Manage classes and subjects
- View system statistics
- Control system data بسهولة

### 👨‍🏫 Teacher Features
- View their schedule
- Add student grades
- Manage classroom data

### 🎓 Student Features
- View grades
- View schedule
- Access personal information

### 👨‍👩‍👧 Parent Features
- متابعة أداء الأبناء
- View student results
- Check attendance
